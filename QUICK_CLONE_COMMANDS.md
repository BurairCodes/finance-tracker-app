# 🚀 Quick Clone Commands

## **Branch Name:**
`bug-fixes/multi-currency-and-receipt-scanner`

## **Repository:**
`https://github.com/BurairCodes/finance-tracker-app.git`

---

## **Method 1: Clone & Switch (Recommended)**
```bash
git clone https://github.com/BurairCodes/finance-tracker-app.git
cd finance-tracker-app
git checkout bug-fixes/multi-currency-and-receipt-scanner
npm install
npx expo start
```

## **Method 2: Clone Branch Directly**
```bash
git clone -b bug-fixes/multi-currency-and-receipt-scanner https://github.com/BurairCodes/finance-tracker-app.git
cd finance-tracker-app
npm install
npx expo start
```

## **Method 3: If You Already Have the Repo**
```bash
cd finance-tracker-app
git fetch origin
git checkout bug-fixes/multi-currency-and-receipt-scanner
npm install
npx expo start
```
