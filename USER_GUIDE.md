# 📱 Finance Tracker App - User Guide

## 🚀 Getting Started

### 1. First Time Setup
1. **Open the app** on your device
2. **Sign up** with your email or use Google Sign-In
3. **Set your base currency** (PKR, USD, EUR, etc.)
4. **Add your first transaction** to get started

### 2. Adding Transactions
- **Tap the + button** on the dashboard
- **Choose transaction type**: Income or Expense
- **Enter amount** and select currency
- **Select category** (Food, Transport, Shopping, etc.)
- **Add description** (optional but helpful)
- **Set date** (defaults to today)
- **Tap Save**

### 3. Managing Budgets
- **Go to Budgets tab**
- **Tap + to create budget**
- **Select category** (e.g., Food & Dining)
- **Set amount** and currency
- **Choose period** (Monthly, Weekly, Yearly)
- **Get alerts** when you exceed budget

## 🔧 Troubleshooting

### Common Issues

**Can't sign in?**
- Check your internet connection
- Try Google Sign-In if email doesn't work
- Contact support if issues persist

**Transactions not saving?**
- Check internet connection
- Try refreshing the app
- Make sure all required fields are filled

**App crashes?**
- Close and reopen the app
- Update to latest version
- Clear app cache if needed
